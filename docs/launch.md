# 资质和提审（roadmap 5.6）

这份文档回答三件事：**上线要办哪些手续、提审前代码里还有哪些没清的、隐私和防沉迷这两块游戏要做什么**。

## 先看这里：哪些是我确定的，哪些要你核对

- **确定的**：游戏实际收集什么数据、用了哪些平台接口、还有哪些东西没在真机上验证过。这些是我读代码和 roadmap 得来的，下面标"项目事实"。
- **要你核对的**：平台的资质、审核、隐私、防沉迷规则。**我没能读到微信、抖音的官方文档**：写这份文档时 `developers.weixin.qq.com`、`developer.open-douyin.com` 被云环境的网络策略挡住了，我只看到了搜索结果里的摘要和二手文章（知乎、CSDN、开发者社区）。这些规则会改，我不知道摘要对应的是哪一年的版本。所以下面标"二手资料"的，**一律以你在微信公众平台、抖音开发者后台里看到的为准**；和我写的不一样，以后台为准，并告诉我，我改这份文档。
- 想让我直接读官方文档：在环境设置里把这两个域名加进允许列表（云环境菜单 → Edit → Network access → Custom，Allowed domains 里加 `developers.weixin.qq.com`、`developer.open-douyin.com`，保留默认的包管理器列表）。步骤见 <https://code.claude.com/docs/en/cloud-environments#network-access>。加完告诉我，我会对着原文把"二手资料"那几条逐条核实。

## 1. 要办的手续

| 事项 | 微信 | 抖音 | 要多久（二手资料） | 说明 |
|---|---|---|---|---|
| 主体认证、注册 AppID | 要 | 要 | 几天 | 先定主体：个人，还是个体户 / 公司（见下） |
| **软件著作权** | 游戏类目要软著或电子版权认证证书（个人可办电子版） | **必须**，且要唯一、与游戏名称一致 | 电子版约 10 天，纸质 1～2 个月 | **最早开始办**，卡在它后面的事最多 |
| ICP 备案 | 要 | 要（先过测试版本审核再提交备案） | 约 10～15 个工作日 | 和软著可以并行 |
| 版号 | 个人主体、免费、只靠广告变现：不需要 | 同左 | — | 一旦开内购、或用公司主体做付费，就要版号。游戏设计里没有内购 |
| 流量主（广告） | 有用户量门槛（路线图原来写的是 500 UV，以后台为准） | 据说上线前就能开，没有这个门槛 | — | 没开通前用模拟广告（已实现） |

**主体怎么选**（二手资料）：个人主体能上线、能开流量主，但**不能接支付**，收款方式也有限制（抖音上个人主体不能委托公司代收）。游戏是免费 + 广告，个人主体够用。以后想加内购，要换个体户或公司主体并申请版号，所以**主体一旦定了换起来麻烦，先想清楚**。

**抖音小游戏名称注销不了**（二手资料）：名字一旦生效就只能转让，所以取名字要谨慎，并且要和软著登记名称一致。游戏现在的名字是"整理行李箱"（`docs/design.md`），软著登记前确认这个名字没有被占用。

## 2. 隐私：游戏实际收集什么（项目事实）

读代码得出的清单，**这是填隐私保护指引和写隐私政策的依据**：

| 数据 | 在哪里 | 去哪里 | 备注 |
|---|---|---|---|
| 进度（当前关卡、进行中的局面、上次插屏时间） | 本机存储，key `progress` | 不出本机 | 没有服务器 |
| 静音设置 | 本机存储，key `settings` | 不出本机 | |
| 玩法事件：开始/通关/重来/跳关、看广告、点分享、侧边栏（共 10 个，见 [analytics.md](analytics.md)） | `wx.reportEvent` / `tt.reportAnalytics` | 微信、抖音自己的后台统计 | 字段只有关卡号、提示次数、通关用时、是否看完广告等；**没有玩家标识**，不含任何个人信息 |
| 广告 | 平台的广告组件 | 平台和广告联盟 | 游戏不碰广告数据；广告组件会不会收集设备信息，由平台的说明为准 |
| 分享 | `shareAppMessage` | 平台的分享面板 | 游戏只给出标题和 `from=share&level=N` |
| 抖音录屏 | `getGameRecorderManager` | 视频留在玩家手机里，玩家点"分享录屏"才发布 | 录的是游戏画面；游戏没有申请麦克风（`start` 只传了时长）。**录屏里会不会带上 5.4 的游戏音效，由平台决定，我不知道**，真机分享一次听听 |

**游戏没有做的事**：不登录、不读用户昵称头像、不申请位置、相机、麦克风、通讯录、剪贴板、不调用任何授权接口、没有自己的服务器、没有账号、没有聊天和排行榜。我在 `src` 里搜过 `getUserInfo`、`login`、`authorize`、`location`、`camera`、`microphone`、`getSetting`：只有 Web 调试入口里的 `window.location`（读网址参数、刷新页面）命中，和用户信息无关。

**怎么填隐私保护指引**（二手资料）：
- 微信：小游戏后台"设置 → 服务内容声明 → 用户隐私保护指引"。**不配置会过不了审核**。如果游戏不处理任何用户个人信息，有一个"确认承诺未处理用户任何信息"的选项，不用走后面的流程；有处理就要更新并配置隐私政策。
- **该选哪个，我拿不准，请你对着后台的说明判断**：游戏本身不处理个人信息，但接了平台的广告组件和统计，平台可能要求你声明"广告""设备信息"之类。后台的选项里如果有"使用了广告服务"的勾选，照实勾。
- 隐私政策文字草稿在 [privacy-policy-draft.md](privacy-policy-draft.md)，里面凡是 `【】` 括起来的都要你填（联系方式、主体名称、生效日期）。**这是草稿，不是法律意见**，平台后台的选项和你的主体情况可能要求不同的措辞；有条件的话让懂行的人看一眼。

## 3. 防沉迷和适龄提示

**游戏自己不用做防沉迷逻辑**（二手资料，来自抖音开放平台的一则通知和微信开发者社区的帖子，具体时间我没看到）：
- 微信：小游戏统一走微信账号的实名认证和腾讯的健康系统，未成年玩家的时长限制由平台管。
- 抖音：据通知，所有小游戏都要接入防沉迷，由平台通过 SDK 升级完成，**开发者不需要自己操作**（有版号的游戏另有要在中宣部实名系统里做的事，我们没有版号，不涉及）。
- 所以游戏里不加实名、不加时长限制。这和设计一致：游戏没有登录。

**适龄提示**：微信后台有"适龄提示设置"（二手资料：有这个入口），抖音规范里也要求按游戏情况给出适龄提示。要填的内容以后台问卷为准。可以对照的事实：没有暴力、恐怖、血腥；没有内购和充值；没有聊天和用户生成内容；有激励视频和插屏广告；内容是整理行李。

## 4. 提审前代码里要清掉的事（项目事实）

这些都是前面各任务里记下的"没验证"或"占位"，提审前逐条清：

| 事项 | 状态 | 怎么清 |
|---|---|---|
| **appid 占位** | `platforms/*/project.config.json` 里是 `touristappid` / `tt00000000000000000` | 换成你注册的 AppID（导入开发者工具时填的会盖过它，但最终提交的工程要是对的） |
| **广告位 id** | `src/entry/wechat.ts`、`douyin.ts` 的 `AD_UNITS` 是空字符串，现在走模拟广告 | 开通流量主、申请广告位后填进去，重新构建。**真广告从来没验证过**：看完给奖励、中途关闭不给、连着看两次、断网时点提示，都要在真机上走一遍（4.2） |
| 抖音接口签名 | `src/platform/douyin.ts` 里 `tt` 的接口（广告、分享、录屏、侧边栏、埋点、音效）是照微信写法推的，没对照官方文档。4.3、4.4 你在真机上验过没问题；4.2 的真广告、5.4 的音效没验 | 开发者工具或真机里走一遍，报错贴给我 |
| **音效** | 5.4 代码已就绪，声音没人听过 | 两个开发者工具里听一遍；iOS 静音键的影响只能真机看 |
| 埋点后台配置 | 事件在代码里已经上报，后台没配收不到 | 按 [analytics.md](analytics.md) 在微信、抖音后台配 10 个事件和字段。各平台对事件和字段数量的限制我没查过 |
| 分享的链接参数 | `from=share&level=N` 没人读，对方点开永远是自己的进度 | 想改要先写 ADR，见 [backlog](backlog.md) |
| 包体 | 三个产物各约 52KB，`npm run check:size` 上限 300KB | 微信、抖音各有主包大小上限（我记得微信是 4MB，抖音没印象，**以后台为准**）；我们离得很远，没有分包问题 |
| 域名白名单 | 游戏不发网络请求 | 不需要配 request 合法域名 |
| 调试入口 | `?level=N&hints=N` 只有 Web 入口认，小游戏产物里没有 | 不用动 |
| 构建产物 | `npm run build:wechat`、`build:douyin` 产出 `dist/wechat/`、`dist/douyin/` | 提审用这两个目录 |

## 5. 提审要准备的材料（二手资料 + 通用）

具体尺寸、字数、格式以后台为准，我列出来是为了你提前备齐：

- 小游戏名称（与软著一致）、简介、**图标**、**截图**（竖屏，建议 375×667、390×844 各一组，可以用 `npm run smoke` 同样的方式截）
- 类目：休闲 / 益智一类，在后台选
- 软著证书（电子版）、ICP 备案号、主体资质
- 隐私保护指引（见上）、适龄提示
- 客服联系方式
- 审核说明 / 测试账号：游戏没有登录，不需要测试账号。可以写一段操作说明："打开即玩，拖动物品进箱子，点一下旋转，全部装下就能过关；提示和跳关需要看激励视频"。
- 真机验证记录：广告、分享、音效、录屏这几项，你验收过的结论

## 6. 时间线：什么先做

软著和备案最慢，且彼此不依赖。建议顺序：

1. **现在就定主体**，同一天开始办电子软著（约 10 天）。
2. 抖音的备案要等测试版本过审后才能提交，所以**尽早提交一个测试版本**，备案（10～15 个工作日）就和软著并行。
3. 等待期间：阶段 5.5 美术（换图后重新截图）、真机验证清单（上面第 4 节）、配埋点。
4. 软著、备案下来之后：填 AppID 和广告位 id → 构建 → 提审。
