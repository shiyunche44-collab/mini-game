# 玩法设计（MVP）

一句话：把行李拖进箱子，全部装下就出发。

## 核心玩法

- 箱子是一个网格。物品是形状贴近实物的多格块：靴子是 L 形，牛仔裤是 ∩ 形，电脑占 2×3。
- 把物品从托盘拖进箱子。点一下物品可以旋转，只能旋转，不能翻面。
- 全部装下就过关。
- 竖屏，单手就能玩。

## 包装

- 每一关是一次出行，关卡名用真实的机场三字码（HGH 杭州、CTU 成都……）。
- 过关后合盖、盖章，弹出登机牌作为结算页，然后进入"下一站"。

## 关卡

- 由程序生成，每关保证有解，同一关所有玩家看到的都一样（[ADR 0003](adr/0003-deterministic-levels.md)）。
- 难度由三样东西决定：箱子尺寸、物品形状的复杂度、拉杆槽（不能放东西的格子）。
- 物品清单见 `src/core/items.ts`，前几关的教学节奏和难度循环见 `src/core/levels.ts` 的 `PRESETS` 和 `CYCLE`；`npm run levels:preview` 可以看生成出来的关卡。

## 没有失败，只有求助

没有失败状态。玩家能做的操作：

| 操作 | 怎么得到 | 规则 |
|---|---|---|
| 重来 | 免费 | 物品全部回到托盘 |
| 提示 | 激励视频 | 看完才给，中途关闭不给 |
| 跳关 | 激励视频 | 看完才跳，中途关闭不跳 |

关卡之间有插屏广告：通关第 5、8、11…… 关后弹，且离上一次不足 90 秒就不弹（不往后顺延）。跳关是看完激励视频换来的，跳关后不弹。

广告位还没开通时（流量主有用户量门槛），用模拟广告代替。

## MVP 不做

- 内购：需要版号，个人基本拿不到。
- 服务器、多人、排行榜。
- 平台特色能力只做这几样：分享（两端）、抖音录屏分享、抖音侧边栏复访（阶段 4）。
