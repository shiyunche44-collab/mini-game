# 美术规格：物品图标（roadmap 5.5）

**我生成不了图片**，这个环境里没有图像生成工具。所以分工是：**你用 AI 画图工具出图，按这份规格；我做游戏里读图、画图、没图时退回 emoji 的那一层。** 图放进 `assets/icons/`，游戏就会用上。

## 画什么、画在哪

现在每件物品是"每格一块彩色圆角方块 + 一个 emoji"。**方块保留**（形状一眼看得清，是玩法的一部分，也不用 AI 去画"L 形的靴子"），**只把 emoji 换成 AI 画的图标**：

- 图标画在原来 emoji 的位置（物品的中心格，或 2×2 以上实心块的中央），始终正立，不跟着物品旋转。
- 小物品里图标画成一格那么大，大物品（2×2 以上的实心块）里画成 1.6 格（`game/pieceView.ts` 的 `ICON_CELLS`、`ICON_CELLS_BIG`）。手机上一格最大 56 像素，所以**图标最大显示约 90×90 CSS 像素**，3 倍屏就是约 270 像素，192×192 够用。
- 没有图（还没出、加载失败）的物品继续画 emoji，所以**可以一件一件地换，不用一次出齐**。

## 技术要求

- **PNG，透明背景**，正方形，**192×192**（出大图再缩也行，但最终文件是 192×192）。
- **图案居中**，四周留约 10% 的空白，不要贴边，不要裁切。
- **单个文件尽量不超过 40KB**（17 张加起来不到 700KB）。AI 工具出的 PNG 往往有几百 KB，**要压缩**：用 TinyPNG / Squoosh 之类的工具转成 8 位调色板 PNG，192×192 的卡通图通常能压到 20～40KB。
- 文件名**严格按上表**（小写英文，对应物品 id）。

## 风格要统一（最容易出问题的地方）

17 张要像一套，不是 17 张不同风格的图。建议：

- 风格：**扁平卡通贴纸风**，圆润，粗细一致的深棕色描边（接近游戏里的字色 #4A3728），简单的色块，轻微的高光，**不要写实、不要照片感、不要复杂渐变和纹理**。
- 色彩：明快柔和，和游戏的暖色背景（奶油色 #FFF6E5）、蓝色箱子（#3F6F9E）搭。图标会放在上表那个底色的方块上，**图案本身不要用和底色相同的颜色做主色**（否则看不见），或者带一圈深色描边就没问题。
- 视角：**正面或四分之三侧面**，统一，不要有的俯视有的侧视。
- 不要文字、不要商标和品牌标识、不要人物和脸（玩偶的脸除外）。
- **每张单独出，用同一份风格描述 + 同一个种子或参考图**，出完放在一起比一比，不统一的重出。

### 提示词模板（英文，多数工具更稳；中文工具直接翻成中文）

```
A cute flat cartoon sticker icon of {物品，如 "a hiking boot"}, rounded shapes,
uniform thick dark-brown outline (#4A3728), simple flat colors with a small soft highlight,
three-quarter front view, centered, generous padding, transparent background,
no text, no logo, no shadow on the ground, game asset, 192x192
```

反面提示词（工具支持的话）：`photorealistic, 3d render, gradient, texture, text, watermark, background, shadow, multiple objects`

很多工具出不了真正的透明背景：先出**纯白或纯色背景**，再用 remove.bg / Photoshop / Photopea 抠成透明。

## 版权和合规：出图前后请你确认

**这几条我没法替你确认，也没能读到官方原文**（见 [launch.md](launch.md) 的说明）：

1. **画图工具的服务条款允许商用吗？** 免费档常常不允许、或要署名。上线前必须弄清，并且**留着出图记录**（工具、日期、提示词）。
2. **AI 生成内容的标识要求。** 据我所知国内有 AI 生成合成内容的标识规定，平台提审时可能问"是否使用 AI 生成素材"。**请在微信、抖音后台的提审表单里据实填写**，具体要不要在游戏里加标识，以后台和最新规定为准。
3. **AI 生成图的著作权归属不明确**，不能当成"你拥有独家版权的原创"。不用于商标，不要出和别人作品高度相似的图（别用"in the style of 某某作品"这类提示词）。
4. 软著登记的是**软件**，素材的来源说明可能要写进提审材料，见 launch.md 第 5 节。

## 出图之后

**游戏里读图、画图的那一层已经做好了**（[ADR 0006](adr/0006-platform-load-image.md)）。你只要：

1. 把压缩好的 PNG 按文件名放进 `assets/icons/`（可以一张一张放，没图的物品继续画 emoji）。
2. 跑 `npm run check:assets`：检查文件名是不是物品 id、是不是 PNG、192×192、有没有透明、每张不超过 60KB、总共不超过 1MB。`npm run check` 里也会跑它，不合格的图会被指出来。
3. `npm run dev` 或 `npm run build:web` 就能看到；`npm run build:wechat`、`build:douyin` 产物里会带上 `assets/`。
