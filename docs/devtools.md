# 在微信、抖音开发者工具里试玩（roadmap 4.1 的验收）

4.1 的验收标准是你在两个开发者工具里导入后能玩。自动测试只能证明产物里没有浏览器接口、在假的 `wx` / `tt` 上能启动和响应触摸，**不能代替真正的开发者工具**，尤其是抖音：这边没有它的类型库，`tt` 的接口签名是按和微信相同的写法推的，没有对照过官方文档。

## 构建

```
npm ci
npm run build:wechat   # 产物在 dist/wechat/
npm run build:douyin   # 产物在 dist/douyin/
```

每个产物目录里有三个文件：`game.js`（游戏）、`game.json`（竖屏、不显示状态栏）、`project.config.json`（项目配置）。

## 导入

1. 打开对应的开发者工具，选"导入项目"，目录选 `dist/wechat` 或 `dist/douyin`。
2. 项目类型选**小游戏**。
3. AppID 填你自己的，或者选测试号。`project.config.json` 里的 appid 只是占位（微信 `touristappid`，抖音 `tt00000000000000000`），导入对话框里填的会盖过它。
4. 编译后应该看到背景、第 1 关的箱子和托盘。

## 请你确认这几件事

1. **能打开**：看到画面，没有红色报错。
2. **画面清晰**：文字和边缘不糊（糊说明画布的物理像素没设对）。
3. **触摸**：拖一件物品进箱子；点一下旋转；拖到箱子外松手会退回托盘。多点触摸可以试试两根手指同时按。
4. **存档**：摆几件物品，关掉模拟器重新编译，进度还在。
5. **前后台**：切到后台再回来，游戏接着跑，不会一步跳很远。
6. **刘海**：在带刘海的机型上，顶部的行李牌没有被刘海盖住。
7. **提示、跳关（广告流程，4.2 的验收）**：点"提示"或"跳关"会弹出系统确认框，标题是"模拟广告（广告位还没开通）"。点"领取奖励"才给提示 / 跳关，点"关闭"什么都不给。连着点两次、关掉再点都应该正常。通关第 5、8、11…… 关之后点"下一站"，插屏现在会直接跳过（没填插屏的广告位 id）。

## 分享（4.3 的验收，要真机）

开发者工具的预览能看到分享面板弹出来，但分享出去的卡片、对方点开后的样子、抖音的录屏，只有真机预览才可靠。

1. **登机牌上的"分享给朋友"**：通关后点它，应该弹出系统的分享面板，标题是"我把第 N 关的行李装下了，你能装下吗？"。点了不会进下一关，可以重复点。
2. **右上角菜单的"转发"**：随时点胶囊按钮里的转发，默认标题是"整理行李箱：把行李都装进箱子，就能出发"。
3. **抖音的"分享录屏"**（只有抖音有这个按钮）：玩一关，通关后点它，应该弹出发布视频的页面，视频是刚才这一关的过程。试几种情况：通关后马上点（视频可能还在收尾，应该等一下再弹出来）；连着通关两关再分享；分享时取消（回到登机牌，什么都不发生）；中途跳关再通关。
4. **对方点开**：现在点开分享卡片进的是对方自己的进度（我们还不读链接参数）。如果你觉得应该进分享者的那一关，告诉我，这要排进后面的任务。

## 看到问题怎么报

写"哪个工具 + 哪个机型 + 看到了什么 + 控制台的报错原文"。控制台的报错最有用，尤其是抖音：如果是 `tt.xxx is not a function`，说明那个接口的写法和我推的不一样，我按报错改 `src/platform/douyin.ts`。

## 已知的限制

- **广告：没填广告位 id 时是模拟的**：激励视频弹确认框（没有倒计时），插屏直接跳过。有了广告位 id 之后，填进 `src/entry/wechat.ts`、`src/entry/douyin.ts` 里的 `AD_UNITS`，重新构建就会用真广告；真广告要在真机上验证，开发者工具里的表现不一定和真机一样。
- **埋点是占位**：什么都不做，在 4.4 做。
- **分享和录屏没有任何反馈文字**：分享失败、没录到视频时，点了按钮什么都不发生，也没有"分享失败"的提示。
- **产物的语法等级是 ES2020**（可选链、`??`）。`project.config.json` 里 `es6` 设成了 false，开发者工具不会再转译。很老的手机可能不认，真机预览时留意；要兼容就把 `es6` 改成 true 并降低 esbuild 的 target，包体会变大一点。
- **窗口大小只在启动时读一次**：开发者工具里切换模拟器机型或转屏，要重新编译。
